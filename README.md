Ember Court is an original tactical card duel: you are the Ember Alchemist, duelling Rook the Stone Golem with a 24-card deck across four suits — Ember, Tide, Thorn and Stone, each told apart by colour and shape. Spend mana to strike, guard, heal or surge; match the same suit twice in a row for a surge bonus and a fresh draw, and read Rook's announced intent each turn so you can guard before his big strike lands. First to 0 life loses the court.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static server and open `game/index.html`. No network, no build step. Play with mouse or keyboard: `1`–`7` select a card, `Enter` plays it, `E` ends your turn, `R` starts a new duel.
